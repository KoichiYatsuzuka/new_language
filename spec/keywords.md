# キーワード一覧

Pythonのキーワードを基にしたキーワード一覧。独自の変更点は注記する。

## 変数宣言

| キーワード | 説明 |
|---|---|
| `let` | 一度だけ初期化可能な変数の宣言 |
| `const` | リテラル値が格納される定数の宣言 |
| `mut` | 何度も変更可能な変数の宣言 |

## 値リテラル

| キーワード | 説明 |
|---|---|
| `True` | 真値 |
| `False` | 偽値 |
| `None` | null値 |

## 論理演算子

| キーワード | 説明 |
|---|---|
| `and` | 論理積 |
| `or` | 論理和 |
| `not` | 論理否定 |

## 比較演算子（キーワード形式）

| キーワード | 説明 |
|---|---|
| `in` | メンバーシップテスト（`x in y`） |
| `not in` | メンバーシップ否定（`x not in y`） |
| `is` | 同一性テスト（`x is y`） |
| `is not` | 同一性否定（`x is not y`） |

## 制御フロー

| キーワード | 説明 |
|---|---|
| `if` | 条件分岐 |
| `elif` | 条件分岐（else if） |
| `else` | 条件分岐（その他） |
| `match` | パターンマッチ |
| `for` | forループ |
| `while` | whileループ |
| `break` | ループを抜ける |
| `continue` | 次のイテレーションへ |
| `pass` | 何もしない（プレースホルダ） |
| `return` | 関数から値を返す |
| `yield` | ジェネレータから値を返す |
| `yield from` | ジェネレータに委譲 |
| `block_return` | コードブロックから値を返す（独自拡張） |
| `block_yield` | コードブロックから値を生成する（独自拡張） |
| `block` | 任意のスコープブロックを作成する（独自拡張） |

## 例外処理

| キーワード | 説明 |
|---|---|
| `try` | 例外処理ブロック |
| `except` | 例外をキャッチ |
| `finally` | 常に実行されるブロック |
| `raise` | 例外を発生させる |

## 定義

| キーワード | 説明 |
|---|---|
| `fn` | 関数定義 |
| `class` | クラス定義 |
| `lambda` | 無名関数 |
| `template` | テンプレート定義（独自拡張） |

## インポート

| キーワード | 説明 |
|---|---|
| `import` | モジュールのインポート |
| `from` | インポート元の指定 |
| `as` | エイリアスの指定 |

## スコープ・変数

| キーワード | 説明 |
|---|---|
| `del` | 変数・要素の削除 |
| `global` | グローバルスコープの変数を参照 |
| `nonlocal` | 外側スコープの変数を参照 |

## コンテキストマネージャ

| キーワード | 説明 |
|---|---|
| `with` | コンテキストマネージャの使用 |

## 非同期処理

| キーワード | 説明 |
|---|---|
| `async` | 非同期関数・ループ・コンテキストマネージャの定義 |
| `await` | 非同期処理の待機 |

## アサーション

| キーワード | 説明 |
|---|---|
| `assert` | 条件アサーション |
