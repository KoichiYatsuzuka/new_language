# 演算子一覧

Pythonの演算子を基にした演算子一覧。独自の変更点は注記する。

## 算術演算子

| 演算子 | 説明 | 例 |
|---|---|---|
| `+` | 加算 | `a + b` |
| `-` | 減算 | `a - b` |
| `*` | 乗算 | `a * b` |
| `/` | 除算（浮動小数点） | `a / b` |
| `//` | 整数除算（切り捨て） | `a // b` |
| `%` | 剰余 | `a % b` |
| `**` | べき乗 | `a ** b` |
| `@` | 行列乗算 | `A @ B` |

## 単項演算子

| 演算子 | 説明 | 例 |
|---|---|---|
| `+` | 単項プラス | `+a` |
| `-` | 単項マイナス（符号反転） | `-a` |
| `~` | ビット反転 | `~a` |

## 比較演算子

| 演算子 | 説明 | 例 |
|---|---|---|
| `==` | 等値比較 | `a == b` |
| `!=` | 非等値比較 | `a != b` |
| `<` | 未満 | `a < b` |
| `>` | より大きい | `a > b` |
| `<=` | 以下 | `a <= b` |
| `>=` | 以上 | `a >= b` |

## ビット演算子

| 演算子 | 説明 | 例 |
|---|---|---|
| `&` | ビット積（AND） | `a & b` |
| `\|` | ビット和（OR） | `a \| b` |
| `^` | ビット排他的論理和（XOR） | `a ^ b` |
| `~` | ビット反転（NOT） | `~a` |
| `<<` | 左シフト | `a << n` |
| `>>` | 右シフト | `a >> n` |

## 代入演算子

| 演算子 | 説明 | 例 |
|---|---|---|
| `=` | 代入 | `a = b` |
| `+=` | 加算代入 | `a += b` |
| `-=` | 減算代入 | `a -= b` |
| `*=` | 乗算代入 | `a *= b` |
| `/=` | 除算代入 | `a /= b` |
| `//=` | 整数除算代入 | `a //= b` |
| `%=` | 剰余代入 | `a %= b` |
| `**=` | べき乗代入 | `a **= b` |
| `&=` | ビットAND代入 | `a &= b` |
| `\|=` | ビットOR代入 | `a \|= b` |
| `^=` | ビットXOR代入 | `a ^= b` |
| `<<=` | 左シフト代入 | `a <<= n` |
| `>>=` | 右シフト代入 | `a >>= n` |
| `@=` | 行列乗算代入 | `A @= B` |
| `:=` | ウォルラス演算子（代入式） | `if (n := len(a)) > 10:` |

## アクセス・添字演算子

| 演算子 | 説明 | 例 |
|---|---|---|
| `.` | 属性アクセス | `obj.attr` |
| `[]` | 添字アクセス・スライス | `a[i]`, `a[1:3]` |
| `()` | 関数呼び出し | `f(x)` |

## その他

| 演算子 | 説明 | 例 |
|---|---|---|
| `*` | アンパック（引数展開） | `f(*args)` |
| `**` | 辞書アンパック（キーワード引数展開） | `f(**kwargs)` |
| `->` | 戻り値型アノテーション | `def f() -> int:` |
| `:` | 型アノテーション・スライス区切り | `x: int`, `a[1:3]` |
| `::` | trait属性アクセス | `self::trait.x` |
| `,` | 要素区切り | `(a, b, c)` |
| `;` | 文区切り（非推奨） | `a = 1; b = 2` |
| `...` | Ellipsis（省略記号） | `def f(): ...` |
| `\|` | 型ユニオン（Python 3.10+） | `int \| str` |

## 演算子の優先順位（高い順）

1. `()`, `[]`, `.` — グルーピング・添字・属性アクセス
2. `**` — べき乗
3. `+x`, `-x`, `~x` — 単項演算子
4. `*`, `@`, `/`, `//`, `%` — 乗除算
5. `+`, `-` — 加減算
6. `<<`, `>>` — シフト
7. `&` — ビットAND
8. `^` — ビットXOR
9. `|` — ビットOR
10. `in`, `not in`, `is`, `is not`, `<`, `<=`, `>`, `>=`, `!=`, `==` — 比較・メンバーシップ・同一性
11. `not` — 論理否定
12. `and` — 論理積
13. `or` — 論理和
14. `:=` — ウォルラス演算子
15. `=`, `+=`, `-=`, ... — 代入演算子
